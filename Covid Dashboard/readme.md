# 📊 COVID-19 Excel Dashboard

This project contains an interactive and well-structured Excel Dashboard visualizing global COVID-19 data. The goal of this project is to transform raw data into meaningful insights using Microsoft Excel’s data analysis and visualization capabilities.

---

## 🚀 Features

- ✔️ Dynamic Charts & Visualizations  
- ✔️ Pivot Tables for aggregated insights  
- ✔️ Slicers for interactive filtering  
- ✔️ Clean and user-friendly dashboard layout  
- ✔️ Data cleaning and transformation techniques applied  
- ✔️ Highlights key indicators:  
  - Confirmed Cases  
  - Recoveries  
  - Death Rates  
  - Geographical Spread Over Time

## 📌 How to Use

1. Download the Excel file from this repository.  
2. Open in Microsoft Excel (recommended version: 2016 or later).  
3. Use slicers and filters to explore the data interactively.

## 🎯 Purpose

This dashboard was created as part of a data analytics learning journey and showcases BI (Business Intelligence) capabilities using Excel alone.
